# 密码记录器

这是一个面向个人使用的离线 Android 密码记录器。密码、分类和标签只保存在手机本地；应用不需要账号，不提供云同步，也不会把密码库上传到服务器。

## 手机端功能

- 查看、搜索、新增、修改和删除密码记录。
- 使用分类与标签整理记录。
- 密码默认固定显示八个圆点 `••••••••`，点击当前记录后才显示该条密码。
- 导出加密备份、导入备份和清空全部数据。这三项功能只在手机端提供。

当前版本不做应用内解锁，依赖手机系统提供的屏幕锁或应用锁。建议先为本应用开启系统应用锁，并妥善保管手机和导出的加密备份。

## 从 PC 临时访问手机密码库

1. 让手机和 PC 连接同一个 Wi-Fi；也可以打开手机热点，再让 PC 连接该热点。
2. 在手机中打开“PC 访问”，启动前台服务。手机会显示本次访问的精确地址和六位访问码。
3. 在 PC 的浏览器地址栏中完整输入手机显示的地址，例如 `http://192.168.1.23:8080`。不要使用搜索框，也不要自行改成 `https://`。
4. 在页面中输入手机显示的六位访问码。配对成功后，可以查看和搜索密码，按分类或标签筛选，新增、修改或删除密码，复制账号或密码，逐条显示或隐藏密码，以及创建、重命名和删除分类、标签。
5. 使用结束后，在手机的“PC 访问”页面或常驻通知中停止 PC 访问。页面刷新、服务停止、会话超时或手机网络变化后都需要重新开启并配对。

同一时间只支持一个 PC 客户端。PC 页面中的修改直接作用于手机密码库；数据不会保存为浏览器中的第二份密码库。删除操作会二次确认，手机与 PC 同时修改同一条记录时，PC 会提示版本冲突并刷新，不会静默覆盖。

## 数据与连接说明

- 密码库数据只保存在手机。PC 页面不使用 `localStorage`、`sessionStorage`、IndexedDB 或 Service Worker，页面关闭或断开后会清除当前会话和页面中的敏感内容。已配对页面会低频检查公开的服务 run 标识；该检查不读取密码库，也不会延长 30 分钟会话空闲时间。
- PC 地址是局域网 HTTP，不需要安装证书。页面随 APK 离线提供，不从 CDN 加载脚本；访问码、账号、密码、备注和密码库命令仍使用临时 P-256 ECDH、HKDF-SHA-256 与 AES-256-GCM 在应用层加密和认证。
- 这一设计面向个人可信 PC 和可信局域网。它不提供 HTTPS 服务器身份认证，因此不要在陌生或不可信网络中开启 PC 访问。
- 复制操作会把所选账号或密码写入 PC 的系统剪贴板；应用不会读取剪贴板原有内容。使用后如有需要，请自行清理剪贴板历史。

## 当前版本不包含

- PC 端导入、导出或清空全部数据；这些操作仍在手机端完成。
- 多 PC 同时连接或长期信任某台 PC。
- 浏览器持久化、浏览器扩展或独立 PC 客户端。
- 手机自签名证书、HTTPS 配置流程。
- 账号系统、云同步或任何第三方遥测。

## 本地验证与云构建

仓库的无依赖测试可从项目根目录运行：

```sh
node --test web-tests/*.test.mjs
sh scripts/test-core.sh
sh scripts/test-lan-http.sh
```

`.github/workflows/build-apk.yml` 提供手动触发的 GitHub Actions APK 构建流程。远程仓库和签名 secrets 配置完成后，工作流会先运行完整浏览器、核心 Java、LAN HTTP、Android 设备和 lint 检查，再构建及验证签名 APK。本文不代表云构建或真实设备验收已经执行。
